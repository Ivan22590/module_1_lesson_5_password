# Password Manager - CLI приложение для хранения паролей

CLI-приложение для безопасного хранения паролей с шифрованием и использованием SQLite3.

## Особенности

- Хранение паролей в зашифрованном виде с использованием Fernet из библиотеки cryptography
- Ключ шифрования хранится локально в файле `.key`
- Мастер-пароль для доступа к хранилищу (хранится в виде хеша SHA-256)
- Все данные хранятся в SQLite3 базе данных `passwords.db`
- Интерфейс с меню по номерам команд для удобства использования

## Установка

1. Установите зависимости:
```bash
pip install cryptography
```

2. Запустите приложение:
```bash
python password_manager.py
```

## Использование

### Первый запуск
При первом запуске приложение запросит мастер-пароль и сохранит его в базе данных в виде хеша SHA-256.

### Последующие запуски
При каждом запуске необходимо ввести мастер-пароль для доступа к данным.

## Интерфейс

Приложение использует текстовое меню с номерами команд для удобства использования:

1. Добавить запись
2. Получить пароль
3. Показать список записей
4. Удалить запись
5. Создать новый пароль
6. Выход

При выборе команды 1-5, программа будет запрашивать необходимые данные.

## Команды

### 1. Добавить запись
Добавляет новую запись в хранилище

### 2. Получить пароль
Получает зашифрованный пароль по названию записи

### 3. Показать список записей
Показывает список всех сохранённых записей

### 4. Удалить запись
Удаляет запись по названию

### 5. Создать новый пароль
Генерирует новый случайный пароль

### 6. Выход
Завершает работу приложения

## Структура файлов

- `password_manager.py` - основной файл приложения
- `database.py` - функции работы с SQLite3
- `encryption.py` - функции шифрования
- `utils.py` - вспомогательные функции
- `passwords.db` - база данных SQLite
- `.key` - файл с ключом шифрования

## Требования

- Python 3.6+
- Библиотека `cryptography`
- База данных SQLite3 (входит в стандартную библиотеку Python)

## Безопасность

- Пароли хранятся в зашифрованном виде
- Мастер-пароль хранится в виде хеша SHA-256 с солью
- Ключ шифрования сохраняется в отдельном файле `.key`
- Все данные хранятся локально на компьютере пользователя
